# Contributing to GeoPulse

Thanks for your interest in improving GeoPulse! Bug reports, translations, integrations and fixes are all welcome.

## Before you start

- For larger changes, please open an issue first so we can agree on the approach.
- Keep pull requests focused on one change and describe what it does and how you tested it.
- See the [documentation portal](https://tess1o.github.io/geopulse/) for setup and architecture notes.

### Signing

A bot checks every pull request. The first time you contribute, it will ask you to sign by posting this comment on the pull request:

```
I have read the CLA Document and I hereby sign the CLA
```

You only need to sign once; your signature covers all your future contributions. If the check doesn't update after you sign, comment `recheck`.
